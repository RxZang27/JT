# เจ๊แตง รถเกี่ยวข้าว – ระบบบันทึกงาน

เว็บแอปบันทึกงานเกี่ยวข้าว (ลูกค้า / ไร่-งาน-ตารางวา / ราคา / เก็บจริง / สถานะจ่ายเงิน / ค่าน้ำมัน / ค่าบำรุงรักษา)
พร้อมแดชบอร์ดรายวัน-รายสัปดาห์-รายเดือน และเช็คลิสต์ลูกค้าค้างจ่าย สำรองข้อมูลขึ้น Google Sheet อัตโนมัติ

## ไฟล์ในโฟลเดอร์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (ไฟล์เดียว) |
| `logo.jpg`, `icon-192.png`, `icon-512.png`, `manifest.webmanifest` | โลโก้ และไอคอนสำหรับติดตั้งบนหน้าจอมือถือ |
| `Code.gs` | โค้ด Google Apps Script สำหรับสำรอง/กู้คืนข้อมูล (ไม่ต้องอัปโหลดขึ้น GitHub) |

## 1) ขึ้น GitHub Pages
1. สมัคร/เข้าสู่ระบบ github.com → **New repository** ชื่อเช่น `jaetang-harvest` (เลือก Public)
2. กด **uploading an existing file** แล้วลากไฟล์ `index.html`, `logo.jpg`, `icon-192.png`, `icon-512.png`, `manifest.webmanifest` ขึ้นไป → **Commit changes**
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/jaetang-harvest/`
5. เปิดลิงก์ในมือถือ แล้วเลือก "เพิ่มลงในหน้าจอหลัก" จะใช้งานเหมือนแอป

> หมายเหตุ: ถ้า repo เป็น Public คนอื่นเปิดลิงก์ได้ แต่ **ข้อมูลลูกค้าอยู่ในเครื่อง/Google Sheet ของเจ๊แตงเท่านั้น** ไม่ได้อยู่ใน GitHub

## 2) ตั้งค่าสำรองข้อมูลผ่าน Google Apps Script
1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก `Code.gs` ทั้งหมด แล้วแก้บรรทัด `const SECRET = 'CHANGE_ME';` เป็นรหัสผ่านของตัวเอง
3. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - อนุญาตสิทธิ์ตามที่ Google ขอ
4. คัดลอก URL ที่ลงท้าย `/exec`
5. เปิดเว็บแอป → แท็บ **สำรองข้อมูล** → วาง URL และรหัสผ่านเดียวกัน → **ทดสอบการเชื่อมต่อ**
6. เปิด "สำรองอัตโนมัติ" ไว้ ทุกครั้งที่บันทึกจะส่งขึ้น Google Sheet (แผ่นงาน `งานเกี่ยว`, `ค่าใช้จ่าย`, `ประวัติการสำรอง`)

ถ้าแก้ `Code.gs` ภายหลัง ต้อง **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL จึงจะใช้โค้ดใหม่

## การใช้งาน
- **บันทึกงาน**: กรอกเฉพาะช่องที่มี (ไร่/งาน/ตารางวา) ระบบคำนวณ `ราคา × พื้นที่` ให้ แก้ยอดเก็บจริงได้ (1 ไร่ = 4 งาน, 1 งาน = 100 ตารางวา)
- **ภาพรวม**: เลือกรายวัน/สัปดาห์/เดือน/ทั้งหมด ดูไร่ ยอดเงิน ค่าใช้จ่าย กำไรสุทธิ และกราฟ
- **ค้างจ่าย**: ติ๊กช่องเมื่อได้รับเงิน (กด "ยกเลิก" ได้ทันทีถ้าติ๊กผิด)
- **กู้คืนข้อมูล** (เปลี่ยนเครื่อง/ล้างเครื่อง): แท็บสำรองข้อมูล → วาง URL + รหัส → **กู้คืนจาก Google Sheet**
